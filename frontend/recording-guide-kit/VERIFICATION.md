## 검증 범위와 남은 연결 작업

- 기존 프로젝트 파일은 수정하지 않았습니다. 현재 프로젝트 전체 빌드를 성공했다고 주장하지 않습니다.
- TypeScript 구문과 모듈 번들은 검증했으나, 사용 가능한 `tsc`가 없어 별도의 엄격한 타입 검사는 실행하지 않았습니다.
- 카메라·마이크 권한 요청, 실제 촬영, 세션 API, DB 저장을 실행하지 않았습니다. 제공 컴포넌트는 안내 UI이며 기존 앱의 실제 연결 함수는 부모에서 전달합니다.
- 카메라 점검을 학습 시작 전에 배치하려면 기존 앱의 카메라 연결과 분석 시작 단계를 분리해야 합니다. 전체 촬영 가이드 페이지에는 이 작업이 필요하지 않습니다.
- 저장·보관·삭제 정책은 운영 환경에서 확정한 값을 선택적 `dataPolicy`로 전달해야 합니다. 확인되지 않은 정책을 기본 문구로 제공하지 않았습니다.
- 기존 프로젝트에는 이번 작업 이전부터 변경 파일이 있었습니다. 해당 변경을 수정하거나 되돌리지 않았습니다.
